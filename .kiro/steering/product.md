# Product Overview

Snipt は Windows 向けのスクリーンショット + 注釈ツールです。ScreenPresso の代替として、ホットキー一発で画面を撮り、矢印・四角・テキストなどの注釈を付けて、すぐに共有(クリップボード / ファイル)できることを目指します。個人の業務利用(手順書作成、バグ報告、チャットでの説明)を主な対象とします。

## Core Capabilities

- 常駐 + グローバルホットキーからの即時キャプチャ(範囲 / ウィンドウ / 全画面)
- 撮影直後のクリップボードコピーと編集画面の自動表示
- 注釈編集(矢印、四角、テキスト、ぼかし、切り抜き、番号付きマーカー)
- 自動保存と履歴一覧、注釈の後からの再編集

## Target Use Cases

- 手順書・マニュアル用に、画面の一部を撮って矢印と番号で操作手順を示す
- バグ報告やチャットで、画面の該当箇所を四角で囲みコメントを添えて貼り付ける
- 過去に撮った画像を履歴から開き、注釈を直して再利用する

## Value Proposition

- 軽量(小さな配布サイズ、常駐時の低負荷)で、撮影から貼り付けまでの手数が少ない
- 注釈を元画像と分けて保存するため、何度でも描き直せる
- マルチモニタ・混在 DPI 環境でも正確な位置とサイズで撮れる

## Non-Goals (現時点)

- 動画 / GIF の録画
- macOS / Linux 対応
- クラウドへのアップロード・共有リンク発行
